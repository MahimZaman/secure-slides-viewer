# Secure Slides Viewer

Display slide decks in LearnDash course content with a viewer that checks course access.

## Installation and use

1. Place the `secure-slides-viewer` folder in `wp-content/plugins/`.
2. Activate Secure Slides Viewer in the WordPress Plugins screen.

Activate LearnDash. Configure ConvertAPI credentials for PowerPoint conversion, add a slide deck, and embed it with `[ssv_slide id="123"]`, replacing `123` with its slide ID.
